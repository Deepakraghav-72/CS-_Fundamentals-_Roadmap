# Topic 18 – Routing and Routing Protocols: Static, Dynamic, RIP, OSPF and BGP

## 1. Routing Kya Hota Hai?

Routing ek process hai jisme router decide karta hai ki data packets ko source network se destination network tak kis path se bhejna hai.

Jab hum internet par kisi website ko open karte hain, to data multiple networks aur routers se pass ho sakta hai.

Example:

```text
Your PC
   |
   v
Router A
   |
   v
Router B
   |
   v
Router C
   |
   v
Destination Server
```

Routers routing table ki help se next path decide karte hain.

### Simple Example

Maan lo:

```text
Network A = 192.168.1.0/24
Network B = 192.168.2.0/24
Network C = 192.168.3.0/24
```

Agar Network A se Network C ko data bhejna hai, to router suitable route select karke packet forward karega.

## 2. Router Kaise Routing Karta Hai?

Router incoming packet ka destination IP address check karta hai.

Uske baad routing table mein matching destination route search karta hai.

Router generally **Longest Prefix Match** ke basis par sabse specific matching route choose karta hai.

Agar suitable route milta hai, to packet next hop ya outgoing interface ki taraf forward hota hai.

### Routing Process

```text
Packet Received
      |
      v
Destination IP Check
      |
      v
Routing Table Search
      |
      v
Best Matching Route
      |
      v
Next Hop / Interface
      |
      v
Packet Forwarded
```

Agar route available nahi hai aur default route bhi nahi hai, to packet drop ho sakta hai.

## 3. Routing Table Kya Hoti Hai?

Routing Table ek data structure hai jisme router ko available network routes ki information milti hai.

Example:

| Destination Network | Next Hop           | Interface   |
| ------------------- | ------------------ | ----------- |
| 192.168.1.0/24      | Directly Connected | LAN         |
| 192.168.2.0/24      | 10.0.0.2           | Interface 1 |
| 192.168.3.0/24      | 10.0.0.3           | Interface 2 |
| 0.0.0.0/0           | 10.0.0.1           | WAN         |

### Important Routing Table Terms

- Destination Network: Jis network tak pahunchna hai.
- Next Hop: Agla router jise packet bhejna hai.
- Interface: Packet bhejne ke liye outgoing interface.
- Metric: Route ki preference/cost calculate karne ka value.
- Default Route: Jab specific matching route nahi milta, tab use hone wala route.

## 4. Default Route Kya Hota Hai?

Default Route ek special route hai jo tab use hota hai jab routing table mein destination ke liye koi more-specific matching route nahi milta.

IPv4 default route:

```text
0.0.0.0/0
```

IPv6 default route:

```text
::/0
```

Example:

```text
Your PC
   |
   v
Home Router
   |
   v
ISP Router
   |
   v
Internet
```

Home router ka default route ISP ki taraf ho sakta hai.

## 5. Longest Prefix Match Kya Hota Hai?

Routing mein agar multiple routes destination IP se match karte hain, to router normally sabse zyada specific prefix wala route select karta hai.

Example routing table:

```text
192.168.0.0/16
192.168.1.0/24
192.168.1.128/25
0.0.0.0/0
```

Destination IP:

```text
192.168.1.150
```

Is IP se upar diye gaye sabhi routes match kar sakte hain, lekin `/25` sabse specific route hai.

Isliye router:

```text
192.168.1.128/25
```

select karega.

Important:

Longest Prefix Match aur routing protocol metric alag concepts hain. Prefix matching forwarding decision ka part hai; metrics routes ki selection/installation mein routing protocol ke according kaam karte hain.

## 6. Routing Ke Types

Routing ke three common types:

1. Static Routing
2. Dynamic Routing
3. Default Routing

### A. Static Routing

Static Routing mein network administrator manually routing table mein routes configure karta hai.

Example:

```text
Destination: 192.168.2.0/24
Next Hop: 10.0.0.2
```

Administrator manually router ko batata hai ki destination network tak pahunchne ke liye kaunsa next hop use karna hai.

#### Advantages

- Simple small networks mein useful.
- Predictable routing.
- Routing protocol overhead nahi hota.
- Network administrator ko control milta hai.

#### Disadvantages

- Large networks mein configuration difficult.
- Network topology change hone par manual updates karne pad sakte hain.
- Incorrect configuration se connectivity issue ho sakta hai.
- Automatic route discovery nahi hoti.

### B. Dynamic Routing

Dynamic Routing mein routers routing protocols ka use karke routes automatically learn aur exchange karte hain.

Example protocols:

- RIP
- OSPF
- BGP
- EIGRP

#### Advantages

- Large networks ke liye useful.
- Network changes ke according routes update ho sakte hain.
- Multiple paths available hone par alternative route select ho sakta hai.
- Manual configuration workload reduce hota hai.

#### Disadvantages

- Configuration complex ho sakti hai.
- CPU, memory aur bandwidth use hoti hai.
- Routing loops ya convergence issues possible hain.
- Protocol knowledge ki zaroorat hoti hai.

### Static vs Dynamic Routing

| Static Routing               | Dynamic Routing                   |
| ---------------------------- | --------------------------------- |
| Manually configured          | Protocols se routes learn         |
| Small networks mein useful   | Medium/large networks mein useful |
| Automatic route updates nahi | Automatic route updates possible  |
| Low protocol overhead        | Protocol overhead                 |
| Simple configuration         | Comparatively complex             |

## 7. Routing Protocol Kya Hota Hai?

Routing Protocol rules ka set hota hai jiske through routers routing information exchange karte hain.

Routing protocols help karte hain:

- Routes discover karne mein.
- Routing information share karne mein.
- Network changes detect karne mein.
- Suitable routes select karne mein.
- Alternative paths find karne mein.

Important routing protocols:

1. RIP
2. OSPF
3. BGP
4. EIGRP

## 8. RIP – Routing Information Protocol

RIP ka full form **Routing Information Protocol** hai.

RIP ek Distance Vector routing protocol hai.

Ismein routers apne neighbors ke saath routing information exchange karte hain.

### RIP Kaise Kaam Karta Hai?

RIP destination tak pahunchne ke liye hop count ko metric ke roop mein use karta hai.

Hop Count ka matlab hai destination tak pahunchne ke liye kitne routers cross karne padenge.

Example:

```text
Router A → Router B → Router C → Router D
```

Yahan Router A se Router D tak 3 router hops hain.

### RIP Ki Characteristics

- Distance Vector protocol.
- Metric = Hop Count.
- Maximum usable hop count = 15.
- 16 hops = Unreachable.
- Traditional RIP updates commonly every 30 seconds.
- Small networks ke liye suitable.

### RIP Versions

**RIPv1**

- Classful routing protocol.
- Subnet mask information carry nahi karta.
- VLSM/CIDR support nahi karta.

**RIPv2**

- Classless routing protocol.
- Subnet mask information carry karta hai.
- VLSM/CIDR support karta hai.
- Multicast address `224.0.0.9` use karta hai.

### RIP Limitations

- Large networks ke liye suitable nahi.
- Slow convergence ho sakti hai.
- 15-hop limit hai.
- Hop count actual bandwidth ya latency ko consider nahi karta.

## 9. OSPF – Open Shortest Path First

OSPF ka full form **Open Shortest Path First** hai.

OSPF ek Link State routing protocol hai.

Ye network topology information collect karke shortest-path calculations perform karta hai.

OSPF generally Dijkstra's Shortest Path First (SPF) algorithm use karta hai.

### OSPF Kaise Kaam Karta Hai?

1. Routers neighbors discover karte hain.
2. Routers Link State Advertisements (LSAs) exchange karte hain.
3. Link-state database (LSDB) build hota hai.
4. SPF algorithm best paths calculate karta hai.
5. Routing table update hoti hai.

### OSPF Diagram

```text
        Router A
        /      \
       /        \
  Router B ---- Router C
       \        /
        \      /
        Router D
```

OSPF network topology ke according suitable paths calculate karta hai.

### OSPF Ki Characteristics

- Link State protocol.
- SPF/Dijkstra algorithm.
- Cost metric use karta hai.
- Areas ke through network divide kar sakta hai.
- Fast convergence provide karne ke liye designed hai.
- Large enterprise networks mein commonly used hai.

### OSPF Areas

OSPF networks ko areas mein divide kiya ja sakta hai.

Special area:

```text
Area 0 = Backbone Area
```

Other areas normally backbone area ke through communicate karte hain.

### OSPF Port/Protocol

OSPF TCP ya UDP port use nahi karta.

OSPF IP Protocol Number:

```text
89
```

Important: IP protocol number 89, TCP/UDP port 89 nahi hai.

## 10. BGP – Border Gateway Protocol

BGP ka full form **Border Gateway Protocol** hai.

BGP ek Path Vector routing protocol hai.

Ye different Autonomous Systems (AS) ke beech routing information exchange karne ke liye internet par use hota hai.

### Autonomous System (AS) Kya Hota Hai?

Autonomous System networks ka ek group hota hai jo ek administrative organization ke control mein operate karta hai aur common routing policy follow karta hai.

Har public AS ka unique Autonomous System Number (ASN) hota hai.

Examples:

- Internet Service Providers.
- Large organizations.
- Cloud providers.
- Large network operators.

### BGP Kaise Kaam Karta Hai?

BGP different autonomous systems ke beech network reachability information exchange karta hai.

Example:

```text
AS 100
   |
   v
AS 200
   |
   v
AS 300
```

BGP route selection mein multiple attributes consider karta hai, jaise:

- AS_PATH
- LOCAL_PREF
- NEXT_HOP
- MED
- ORIGIN

Actual best-path selection vendor aur configuration ke according multiple decision rules follow karti hai.

### BGP Ki Characteristics

- Path Vector protocol.
- Internet routing mein important.
- Different Autonomous Systems ke beech routing.
- TCP port 179 use karta hai.
- Policy-based routing decisions support karta hai.
- Large-scale routing ke liye designed hai.

### eBGP vs iBGP

**eBGP (External BGP):**

Different Autonomous Systems ke routers ke beech BGP session.

**iBGP (Internal BGP):**

Same Autonomous System ke routers ke beech BGP session.

## 11. EIGRP Kya Hota Hai?

EIGRP ka full form **Enhanced Interior Gateway Routing Protocol** hai.

EIGRP ek advanced distance-vector / hybrid-style Interior Gateway Protocol hai.

Ye Cisco environment mein historically popular raha hai.

### EIGRP Ki Characteristics

- DUAL algorithm use karta hai.
- Fast convergence support karta hai.
- Bandwidth aur delay jaise metrics consider karta hai.
- Unequal-cost load balancing support karta hai.
- Modern environments mein vendor/platform support verify karna chahiye.

## 12. IGP vs EGP

Routing protocols ko administrative scope ke basis par bhi classify kiya jata hai.

### IGP – Interior Gateway Protocol

IGP ka use ek Autonomous System ke andar routing ke liye hota hai.

Examples:

- RIP
- OSPF
- EIGRP
- IS-IS

### EGP – Exterior Gateway Protocol

EGP ka use different Autonomous Systems ke beech routing ke liye hota hai.

Modern internet mein BGP primary inter-domain routing protocol hai.

| IGP                      | EGP                   |
| ------------------------ | --------------------- |
| Same AS ke andar         | Different AS ke beech |
| Internal network routing | Inter-domain routing  |
| RIP, OSPF, IS-IS, EIGRP  | BGP                   |

Note: EGP ek general category hai. BGP modern internet ka principal inter-domain protocol hai; EGP naam ka historical protocol bhi exist karta tha.

## 13. Distance Vector vs Link State vs Path Vector

| Feature            | Distance Vector        | Link State                   | Path Vector                  |
| ------------------ | ---------------------- | ---------------------------- | ---------------------------- |
| Information        | Distance and direction | Network topology/link states | AS path and route attributes |
| Example            | RIP                    | OSPF, IS-IS                  | BGP                          |
| Main Scope         | Internal routing       | Internal routing             | Inter-domain routing         |
| Algorithm/Approach | Neighbor information   | SPF/Dijkstra                 | Path attributes and policies |
| Example Metric     | Hop count              | Cost                         | Multiple attributes          |

## 14. Routing Metric Kya Hota Hai?

Metric ek value hoti hai jo routing protocol ko routes compare karne mein help karti hai.

Different protocols different metrics use karte hain.

Examples:

| Protocol | Main Metric/Attributes              |
| -------- | ----------------------------------- |
| RIP      | Hop Count                           |
| OSPF     | Cost                                |
| EIGRP    | Composite metric                    |
| BGP      | Multiple path attributes and policy |

Important:

Different routing protocols ke metrics directly comparable nahi hote.

Routers administrative distance jaise concepts ke through different route sources ki preference decide kar sakte hain. Administrative distance vendor-specific terminology/value system hai; ise routing protocol metric se confuse mat karna.

## 15. Convergence Kya Hoti Hai?

Convergence wo process hai jisme network topology change hone ke baad routers routing information update karke consistent routing state establish karte hain.

Example:

```text
Before:
Router A → Router B → Router C

Router B Link Failed

After:
Router A → Router D → Router C
```

Agar alternative route available hai, to routing protocol us route ko learn/select kar sakta hai.

Fast convergence ka matlab network failure ke baad relatively quickly stable routing restore hona.

## 16. Routing Loop Kya Hota Hai?

Routing Loop tab hota hai jab packets routers ke beech repeatedly circulate karte rehte hain aur destination tak nahi pahunchte.

Example:

```text
Router A → Router B
    ↑         |
    |         v
    └──── Router C
```

### Prevention Techniques

- Split Horizon.
- Route Poisoning.
- Hold-down timers.
- TTL / Hop Limit.
- Proper routing protocol configuration.

RIP mein split horizon aur route poisoning jaise mechanisms routing loop problems reduce karne mein help karte hain.

## 17. Static Route vs Default Route vs Dynamic Route

| Type          | Meaning                                   |
| ------------- | ----------------------------------------- |
| Static Route  | Manually configured route                 |
| Default Route | Fallback route for unmatched destinations |
| Dynamic Route | Routing protocol se learned route         |

Important: Default route static bhi ho sakti hai aur dynamic routing protocol se bhi learn ho sakti hai.

## 18. Windows Mein Routing Table Kaise Check Karein?

Windows CMD open karo.

### Command 1: Routing Table

```cmd
route print
```

Ye system ki IPv4 aur IPv6 routing tables show karta hai.

### Command 2: IP Configuration

```cmd
ipconfig /all
```

Network interface aur default gateway details check karne ke liye.

### Command 3: Traceroute

```cmd
tracert google.com
```

Ye destination tak network path ke hops identify karne mein help karta hai.

### Command 4: PathPing

```cmd
pathping google.com
```

Ye route tracing aur hop-level packet loss/latency analysis mein help karta hai.

Note: Firewalls, ICMP filtering aur network configuration ki wajah se kuch hops ka response nahi aa sakta. Iska matlab hamesha ye nahi ki router down hai.

## 19. Routing vs Forwarding

Dono related hain, lekin same nahi hain.

**Routing:**

Best path ya route determine karne ka control-plane process.

**Forwarding:**

Incoming packet ko selected outgoing interface/next hop ki taraf bhejne ka data-plane process.

| Routing                           | Forwarding                        |
| --------------------------------- | --------------------------------- |
| Path selection                    | Packet movement                   |
| Control plane                     | Data plane                        |
| Routing information use karta hai | Forwarding table use karta hai    |
| Route calculate/learn karta hai   | Packet ko next hop par bhejta hai |

## 22. Common Mistakes

1. Routing aur forwarding ko same samajhna.
2. Routing table ko MAC address table samajhna.
3. RIP ko Link State protocol kehna.
4. OSPF ko Distance Vector protocol kehna.
5. BGP ko ordinary shortest-distance protocol samajhna.
6. OSPF protocol number 89 ko TCP port 89 kehna.
7. RIP ki maximum usable hop count 16 samajhna.
8. Default route ko hamesha static route samajhna.
9. Metric aur administrative distance ko same samajhna.
10. Convergence ko packet forwarding ke equal samajhna.
