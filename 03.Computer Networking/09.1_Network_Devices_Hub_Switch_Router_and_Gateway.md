# Topic 09 – Network Devices: Hub, Switch, Router, Bridge, Repeater and Gateway

## 1. Network Devices Kya Hote Hain?

Network Devices wo hardware devices hote hain jo computers aur doosre devices ko network mein connect karne, data transfer karne aur communication manage karne mein help karte hain.

Example:

- Hub
- Switch
- Router
- Bridge
- Repeater
- Gateway
- Modem
- Access Point
- Network Interface Card (NIC)

## 2. Network Devices Ki Zaroorat Kyon Hoti Hai?

Maan lo ek office mein 20 computers hain.

Sabhi computers ko ek-doosre se communicate karna hai aur internet bhi use karna hai.

Iske liye network devices ki zaroorat hogi.

```text
PC 1 ──┐
PC 2 ──┤
PC 3 ──┤
PC 4 ──┼── Switch ── Router ── Internet
PC 5 ──┤
PC 6 ──┘
```

- Switch local devices ko connect karega.
- Router alag networks ko connect karega.
- Internet connection ke liye router traffic forward karega.

## 3. Hub Kya Hota Hai?

Hub ek basic networking device hai jo multiple computers ko ek LAN mein connect karta hai.

Hub OSI Model ki **Physical Layer (Layer 1)** par kaam karta hai.

### Hub Kaise Kaam Karta Hai?

Maan lo 4 computers hub se connected hain.

Computer A data send karta hai.

Hub received signal ko apne baaki connected ports par repeat karta hai.

```text
       PC A
         |
         |
       HUB
      / |  \
     /  |   \
   PC B PC C PC D
```

Agar PC A data bhejta hai, to hub us signal ko PC B, PC C aur PC D tak bhej deta hai.

Destination device data accept karta hai; baaki devices ignore kar dete hain.

### Hub Ki Characteristics

- Physical Layer par kaam karta hai.
- MAC address ko inspect nahi karta.
- Received signal ko baaki ports par repeat karta hai.
- Bandwidth shared hoti hai.
- Traditional Ethernet hub mein ek collision domain hota hai.
- Half-duplex communication hota hai.
- Modern networks mein mostly switches ne hub ko replace kar diya hai.

### Hub Ke Types

1. Active Hub – Signal ko regenerate/amplify karke forward karta hai.
2. Passive Hub – Signal ko amplify kiye bina connections distribute karta hai.
3. Intelligent Hub – Monitoring/management jaise basic features provide kar sakta hai.

## 4. Switch Kya Hota Hai?

Switch ek networking device hai jo multiple devices ko Local Area Network (LAN) mein connect karta hai.

Switch normally OSI Model ki **Data Link Layer (Layer 2)** par kaam karta hai.

Layer 2 switch MAC Address ke basis par Ethernet frames forward karta hai.

### Switch Kaise Kaam Karta Hai?

Maan lo 4 computers switch se connected hain.

PC A ko PC C ko data bhejna hai.

Switch destination MAC address check karke frame ko correct port par forward karta hai, agar destination MAC table mein known hai.

```text
PC A ──┐
PC B ──┤
PC C ──┼── SWITCH
PC D ──┘
```

Agar destination MAC unknown hai, to switch incoming port ko chhodkar same VLAN ke baaki ports par frame flood kar sakta hai.

### Switch Ki Characteristics

- Normally Layer 2 par kaam karta hai.
- MAC address table maintain karta hai.
- MAC address ke basis par frames forward karta hai.
- Har switch port apna alag collision domain banata hai.
- Full-duplex communication support karta hai.
- Har port ko dedicated bandwidth mil sakti hai.
- VLAN support kar sakta hai.

### Switch MAC Address Table Kaise Banata Hai?

Switch incoming frames ke source MAC address ko dekhkar us MAC ke saath incoming port associate karta hai.

Example:

| MAC Address       | Switch Port |
| ----------------- | ----------- |
| AA:AA:AA:AA:AA:AA | Port 1      |
| BB:BB:BB:BB:BB:BB | Port 2      |
| CC:CC:CC:CC:CC:CC | Port 3      |

Is table ki help se switch decide karta hai ki frame kis port par forward karna hai.

## 5. Router Kya Hota Hai?

Router ek networking device hai jo different IP networks ko connect karta hai.

Router OSI Model ki **Network Layer (Layer 3)** par kaam karta hai.

Router IP Address ke basis par packets ko forward karta hai.

### Router Kaise Kaam Karta Hai?

Maan lo:

- Network A = `192.168.1.0/24`
- Network B = `192.168.2.0/24`

Dono networks ko communicate karna hai.

Router in dono networks ke beech packets forward kar sakta hai.

```text
Network A                 Network B

PC 1                       PC 2
  |                          |
Switch A                  Switch B
  |                          |
  └────── ROUTER ────────────┘
```

### Router Ki Characteristics

- Normally Layer 3 par kaam karta hai.
- IP address ke basis par routing karta hai.
- Routing table maintain karta hai.
- Different networks ko connect karta hai.
- Broadcast domains ko separate karta hai.
- Default gateway ke roop mein kaam kar sakta hai.
- NAT, firewall aur DHCP jaise additional features bhi provide kar sakta hai, model/configuration par depend karta hai.

### Routing Table Kya Hoti Hai?

Routing table mein network destinations aur un tak pahunchne ke liye next-hop/interface ki information hoti hai.

Example:

| Destination Network | Next Hop / Interface |
| ------------------- | -------------------- |
| 192.168.1.0/24      | Interface 1          |
| 192.168.2.0/24      | Interface 2          |
| 0.0.0.0/0           | Default route        |

Router destination IP ke basis par best matching route choose karta hai.

## 6. Bridge Kya Hota Hai?

Bridge ek networking device hai jo do ya zyada LAN segments ko connect karta hai.

Ye OSI Model ki **Data Link Layer (Layer 2)** par kaam karta hai.

Bridge MAC address ke basis par frames ko filter aur forward karta hai.

### Bridge Kaise Kaam Karta Hai?

```text
LAN Segment A       LAN Segment B

 PC 1                  PC 3
 PC 2                  PC 4
   |                     |
   └────── BRIDGE ───────┘
```

Bridge MAC addresses learn karta hai aur decide karta hai ki frame ko doosre segment mein forward karna hai ya nahi.

### Bridge Ki Characteristics

- Layer 2 device.
- MAC address ke basis par forwarding.
- Network segments ko connect karta hai.
- Collision domains ko separate karta hai.
- Broadcast traffic ko normally forward karta hai.
- Modern networks mein switches ne mostly traditional bridges ko replace kar diya hai.

**Important:** Switch ko multiport bridge ka advanced form samajh sakte ho.

## 7. Repeater Kya Hota Hai?

Repeater ek networking device hai jo weak signal ko receive karke regenerate karta hai aur aage transmit karta hai.

Repeater OSI Model ki **Physical Layer (Layer 1)** par kaam karta hai.

### Repeater Kaise Kaam Karta Hai?

Maan lo network cable ya wireless signal distance ki wajah se weak ho raha hai.

Repeater signal ko regenerate karke communication distance badhane mein help karta hai.

```text
Device A ─── Weak Signal ─── REPEATER ─── Regenerated Signal ─── Device B
```

### Repeater Ki Characteristics

- Layer 1 device.
- Signal regenerate karta hai.
- Signal coverage/distance badhane mein help karta hai.
- MAC ya IP address ke basis par routing nahi karta.
- Signal ke content ko interpret nahi karta.

### Wi-Fi Repeater

Wi-Fi repeater wireless signal receive karke usse aage retransmit karta hai.

Isse coverage improve ho sakti hai, lekin actual performance placement, interference aur repeater technology par depend karti hai.

## 8. Gateway Kya Hota Hai?

Gateway ek device ya software system hota hai jo different networks ya systems ke beech communication ka path provide karta hai.

Gateway ka meaning context ke according change ho sakta hai.

### Default Gateway

Computer ke network mein Default Gateway wo router/interface hota hai jiske through device apne local network ke bahar traffic bhejta hai.

Example:

```text
Your PC:
IP = 192.168.1.10

Default Gateway:
IP = 192.168.1.1

Remote Server:
IP = 8.8.8.8
```

Jab tumhara PC `8.8.8.8` se communicate karega, to wo packet default gateway ko bhejega.

### Gateway Ki Characteristics

- Different networks ke beech communication mein help karta hai.
- Default gateway usually router ka IP address hota hai.
- Kuch gateways different protocols ya data formats ke beech translation karte hain.
- Gateway ek general networking concept hai, sirf ek specific OSI layer tak limited nahi hai.

## 9. Modem Kya Hota Hai?

Modem ka full form **Modulator-Demodulator** hai.

Modem communication medium ke according signals ko modulate aur demodulate karta hai.

Simple words mein, modem internet service provider ke network se connection establish karne mein help karta hai.

### Modem Ke Types

- DSL Modem
- Cable Modem
- Cellular Modem
- Fiber ONT (Optical Network Terminal) – Fiber networks mein similar customer-side termination role, although technically traditional modem se different.

### Modem vs Router

| Modem                                                | Router                                     |
| ---------------------------------------------------- | ------------------------------------------ |
| ISP connection terminate karta hai                   | Networks ke beech traffic route karta hai  |
| Access technology par depend karta hai               | IP packets forward karta hai               |
| Internet connection provide karne wale setup ka part | Local network devices ko connect karta hai |
| Routing feature hona zaroori nahi                    | Routing iska main function hai             |

Note: Aajkal kai devices modem/ONT aur router dono ke features ek hi box mein provide karte hain.

## 10. Wireless Access Point (WAP) Kya Hota Hai?

Wireless Access Point ek device hai jo Wi-Fi devices ko wired LAN se connect karta hai.

Example:

```text
Laptop )))
Mobile ))) ─── Access Point ─── Switch ─── Router
Tablet )))
```

### Access Point Ki Characteristics

- Wi-Fi connectivity provide karta hai.
- Wireless devices ko LAN se connect karta hai.
- Wireless network ka coverage badhane mein help karta hai.
- Enterprise networks mein multiple APs use kiye ja sakte hain.

### Access Point vs Router

| Access Point                                           | Router                                            |
| ------------------------------------------------------ | ------------------------------------------------- |
| Wireless clients ko LAN se connect karta hai           | Different IP networks ko connect karta hai        |
| Usually routing nahi karta                             | Routing karta hai                                 |
| Existing network ka Wi-Fi access provide kar sakta hai | Routing, NAT aur DHCP jaise features de sakta hai |

Home Wi-Fi router mein router aur access point dono functions ho sakte hain.

## 11. Layer 2 Switch vs Layer 3 Switch

Layer 2 switch MAC addresses ke basis par frames forward karta hai.

Layer 3 switch MAC ke saath IP routing bhi perform kar sakta hai.

| Layer 2 Switch                         | Layer 3 Switch                                 |
| -------------------------------------- | ---------------------------------------------- |
| Data Link Layer                        | Data Link + Network Layer functions            |
| MAC-based forwarding                   | MAC switching + IP routing                     |
| VLAN ke andar frames forward karta hai | Different VLANs ke beech routing kar sakta hai |
| Normally routing nahi karta            | Routing support karta hai                      |

## 12. Hub vs Switch vs Router

Ye sabse important interview comparison hai.

| Feature          | Hub                        | Switch                | Router                                   |
| ---------------- | -------------------------- | --------------------- | ---------------------------------------- |
| OSI Layer        | Layer 1                    | Usually Layer 2       | Layer 3                                  |
| Address          | Address inspect nahi karta | MAC                   | IP                                       |
| Main Work        | Signals repeat             | Frames forward        | Packets route                            |
| Data Unit        | Bits/signals               | Frames                | Packets                                  |
| Collision Domain | Shared                     | Per port              | Per interface/boundary                   |
| Broadcast Domain | Shared                     | Same VLAN mein shared | Interfaces ke beech separated by default |
| Intelligence     | Very low                   | Medium                | Routing decisions                        |
| Modern Use       | Rare                       | Common                | Common                                   |

Note: Layer 3 switches bhi hote hain. Is table mein ordinary Layer 2 switch compare kiya gaya hai.

## 13. Collision Domain vs Broadcast Domain

### Collision Domain

Collision domain wo network segment hota hai jahan shared half-duplex medium par simultaneous transmissions collide kar sakti hain.

- Hub ke sabhi ports ek shared collision domain mein hote hain.
- Switch ke har port ka separate collision domain hota hai.
- Full-duplex switched Ethernet mein collisions normally nahi hoti.

### Broadcast Domain

Broadcast domain wo logical network area hota hai jahan Layer 2 broadcast frames pahunchte hain.

- Hub connected devices same broadcast domain mein hote hain.
- Same VLAN ke switch ports ek broadcast domain share karte hain.
- Router interfaces normally separate broadcast domains banate hain.
- VLANs broadcast domains ko logically divide karti hain.

## 14. Real-Life Network Example

Maan lo tumhare ghar mein:

- 2 laptops
- 3 mobile phones
- 1 Smart TV
- 1 Wi-Fi router

Network ka basic structure:

```text
              INTERNET
                  |
               ISP/ONT
                  |
                ROUTER
                  |
          -----------------
          |               |
       Wi-Fi           Ethernet
          |               |
    -------------       Switch
    |     |     |         |
  Mobile Laptop TV      Desktop
```

Router devices ko local IP addresses de sakta hai through DHCP, wireless access provide kar sakta hai aur internet traffic route kar sakta hai.

## 15. Windows Practical Commands

### IP Configuration

```cmd
ipconfig /all
```

IP, MAC aur Default Gateway check karne ke liye.

### ARP Table

```cmd
arp -a
```

Local ARP mappings check karne ke liye.

### Routing Table

```cmd
route print
```

Computer ki routing table dekhne ke liye.

### Gateway Connectivity

```cmd
ping 192.168.1.1
```

Yahan `192.168.1.1` ko apne actual Default Gateway IP se replace karna.

Gateway IP check karne ke liye:

```cmd
ipconfig
```

## 17. Important Interview Questions

**Q1. Hub kya hai?**

Hub Layer 1 device hai jo received signals ko baaki connected ports par repeat karta hai.

**Q2. Switch kya hai?**

Switch normally Layer 2 device hai jo MAC address ke basis par Ethernet frames forward karta hai.

**Q3. Router kya hai?**

Router Layer 3 device hai jo IP address ke basis par different networks ke beech packets forward karta hai.

**Q4. Hub aur Switch mein difference?**

Hub received signals ko all other ports par repeat karta hai, jabki switch MAC address table ke basis par frames forward karta hai.

**Q5. Switch aur Router mein difference?**

Switch normally same LAN/VLAN mein MAC-based forwarding karta hai, jabki router different IP networks ke beech routing karta hai.

**Q6. Bridge kya hai?**

Bridge Layer 2 device hai jo network segments ko connect aur MAC address ke basis par frames filter karta hai.

**Q7. Repeater kya karta hai?**

Repeater weak signal ko regenerate karke aage transmit karta hai.

**Q8. Default Gateway kya hota hai?**

Default Gateway wo next-hop device hota hai jiske through computer apne local network ke bahar traffic bhejta hai.

**Q9. Modem aur Router mein kya difference hai?**

Modem/ONT ISP access connection terminate karta hai, jabki router IP traffic ko different networks ke beech forward karta hai.

**Q10. Access Point kya hai?**

Access Point wireless devices ko Wi-Fi ke through wired LAN se connect karta hai.

**Q11. Switch mein MAC Address Table ka kya use hai?**

MAC Address Table switch ko batati hai ki particular MAC address kis port par reachable hai.

**Q12. Router broadcast domains ko separate kyon karta hai?**

Router Layer 2 broadcasts ko normally ek interface se doosre interface par forward nahi karta.

## 18. Common Mistakes

1. Hub ko Layer 2 device samajhna.
2. Switch ko IP address ke basis par forwarding karne wala ordinary Layer 2 switch samajhna.
3. Router ko MAC address ke basis par routing karne wala device kehna.
4. Bridge aur repeater ka kaam same samajhna.
5. Default Gateway ko hamesha public IP samajhna.
6. Modem aur router ko same device samajhna.
7. Har switch ko Layer 2 hi samajhna.
8. Same VLAN ke har switch port ko separate broadcast domain samajhna.

## 19. Quick Revision

- Hub = Layer 1, signal repeat.
- Switch = Layer 2, MAC-based frame forwarding.
- Router = Layer 3, IP-based packet forwarding.
- Bridge = Layer 2, network segments connect.
- Repeater = Layer 1, signal regenerate.
- Gateway = Networks/systems ke beech communication path.
- Modem = Modulation/demodulation; ISP access connection.
- Access Point = Wi-Fi clients ko LAN se connect.
- Layer 2 Switch = MAC forwarding.
- Layer 3 Switch = Switching + IP routing.
- Hub = Shared collision domain.
- Switch = Separate collision domain per port.
- Router = Normally separate broadcast domains.
