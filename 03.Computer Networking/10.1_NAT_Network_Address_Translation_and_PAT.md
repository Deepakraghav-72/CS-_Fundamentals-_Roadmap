# Topic 10 – NAT, PAT and Port Forwarding

## 1. NAT Kya Hota Hai?

NAT ka full form **Network Address Translation** hai.

NAT ek networking technique hai jiska use IP addresses ko ek address se doosre address mein translate karne ke liye hota hai.

Mostly NAT ka use private IP addresses wale devices ko public internet access dene ke liye kiya jata hai.

### NAT Ki Zaroorat Kyon Padti Hai?

IPv4 addresses limited hain.

Agar har mobile, laptop, computer aur smart TV ko alag public IPv4 address dena pade, to available IPv4 addresses ki demand bahut badh jayegi.

NAT ki help se multiple devices private IP addresses use karte hue ek ya kuch public IP addresses ke through internet access kar sakte hain.

### Example

Maan lo tumhare ghar mein:

| Device   | Private IP   |
| -------- | ------------ |
| Laptop   | 192.168.1.10 |
| Mobile   | 192.168.1.11 |
| Smart TV | 192.168.1.12 |
| Desktop  | 192.168.1.13 |

Tumhare router ka public IP hai:

```text
49.36.100.25
```

Ye devices router ke through internet access kar sakte hain.

```text
Laptop       192.168.1.10
Mobile       192.168.1.11
Smart TV    192.168.1.12
Desktop      192.168.1.13
       \       |       /
        \      |      /
          ROUTER
        NAT / PAT
             |
       Public IP
      49.36.100.25
             |
          INTERNET
```

Router outgoing traffic ke source IP ko public IP mein translate karta hai.

## 2. Private IP vs Public IP

### Private IP Address

Private IP address local networks ke andar use hota hai.

IPv4 ke private ranges:

| Range                         | CIDR           |
| ----------------------------- | -------------- |
| 10.0.0.0 – 10.255.255.255     | 10.0.0.0/8     |
| 172.16.0.0 – 172.31.255.255   | 172.16.0.0/12  |
| 192.168.0.0 – 192.168.255.255 | 192.168.0.0/16 |

Private IP addresses directly public internet par globally routable nahi hote.

### Public IP Address

Public IP address internet par globally routable address hota hai.

Example:

```text
8.8.8.8
```

Ye Google Public DNS ka IPv4 address hai.

### Difference

| Private IP                                   | Public IP                                      |
| -------------------------------------------- | ---------------------------------------------- |
| Local network mein use                       | Public internet par routing                    |
| Globally unique hona zaroori nahi            | Public routing mein globally unique allocation |
| Directly internet par routable nahi          | Internet par routable                          |
| NAT ke through internet access kar sakta hai | Internet communication mein use hota hai       |

## 3. NAT Kaise Kaam Karta Hai?

Maan lo tumhare laptop ka IP hai:

```text
Private IP: 192.168.1.10
```

Tum internet par ek website open karte ho.

Website ka IP:

```text
Destination IP: 93.184.216.34
```

Tumhara router outgoing packet ka source private IP apne public IP se translate kar deta hai.

Example:

Before NAT:

```text
Source IP      = 192.168.1.10
Destination IP = 93.184.216.34
```

After NAT:

```text
Source IP      = 49.36.100.25
Destination IP = 93.184.216.34
```

Jab response wapas aata hai, router apni translation entry ke according response ko correct internal device tak forward karta hai.

Note: Ye simplified example hai. Real NAT implementations mein packet ke ports, protocol aur connection state bhi important ho sakte hain.

## 4. NAT Translation Table

Router NAT translations ko track kar sakta hai.

Example:

| Internal Private IP | Translated Public IP |
| ------------------- | -------------------- |
| 192.168.1.10        | 49.36.100.25         |
| 192.168.1.11        | 49.36.100.25         |
| 192.168.1.12        | 49.36.100.25         |

PAT use hone par ports bhi translation table mein track kiye jate hain.

Example:

| Private IP:Port   | Public IP:Port     |
| ----------------- | ------------------ |
| 192.168.1.10:5000 | 49.36.100.25:40001 |
| 192.168.1.11:5000 | 49.36.100.25:40002 |
| 192.168.1.12:5000 | 49.36.100.25:40003 |

Is tarah router multiple devices ke connections ko distinguish kar pata hai.

## 5. Types of NAT

NAT ke commonly discussed types:

1. Static NAT
2. Dynamic NAT
3. PAT (Port Address Translation)

### A. Static NAT

Static NAT mein ek private IP address ko ek fixed public IP address se permanently map kiya jata hai.

Example:

```text
Private IP          Public IP
192.168.1.10  --->  49.36.100.10
```

Is mapping ko administrator configure karta hai.

Uses:

- Publicly accessible internal servers.
- Fixed one-to-one address mapping.
- Specific network infrastructure.

### B. Dynamic NAT

Dynamic NAT mein private IP addresses ko available public IP address pool se temporarily map kiya jata hai.

Example:

```text
Public IP Pool:

49.36.100.10
49.36.100.11
49.36.100.12
```

Internal devices jab internet access karte hain, NAT device available public IP assign kar sakta hai.

Agar pool mein public IP available nahi hai, to new translation establish nahi ho sakti.

### C. PAT (Port Address Translation)

PAT ka full form **Port Address Translation** hai.

PAT mein multiple private IP devices ek public IP address share kar sakte hain.

Router port numbers ki help se connections ko distinguish karta hai.

PAT ko commonly NAT Overload bhi kaha jata hai.

Example:

```text
Device A:
192.168.1.10:5000
        |
        v
49.36.100.25:40001

Device B:
192.168.1.11:5000
        |
        v
49.36.100.25:40002

Device C:
192.168.1.12:5000
        |
        v
49.36.100.25:40003
```

Yahan sabhi devices same public IP use kar rahe hain, lekin translated source ports alag hain.

### PAT Ki Characteristics

- Multiple private IPs ko one public IP se share karwa sakta hai.
- Port numbers use karta hai.
- Home routers mein commonly use hota hai.
- IPv4 address conservation mein help karta hai.

## 6. Static NAT vs Dynamic NAT vs PAT

| Feature             | Static NAT                       | Dynamic NAT              | PAT                    |
| ------------------- | -------------------------------- | ------------------------ | ---------------------- |
| Mapping             | Fixed                            | Pool se temporary        | IP + Port mapping      |
| Public IP           | Usually one per internal mapping | Pool se assign           | Multiple devices share |
| Port translation    | Required nahi                    | Required nahi            | Yes                    |
| Common Use          | Internal server mapping          | Enterprise networks      | Home/office internet   |
| One public IP share | Normally no                      | Not through same mapping | Yes                    |

## 7. NAT vs PAT

NAT ek general technique hai jisme IP address translation hoti hai.

PAT NAT ka ek type hai jisme IP addresses ke saath port numbers bhi translate hote hain.

Example:

```text
NAT:
Private IP → Public IP

PAT:
Private IP:Port → Public IP:Port
```

Easy way:

- NAT = Address translation.
- PAT = Address + Port translation.

## 8. Port Forwarding Kya Hota Hai?

Port Forwarding ek router configuration hai jisme incoming traffic ko specific public port se internal device/server ke specific IP aur port par forward kiya jata hai.

Iska use internet ke bahar se internal network ke kisi service ko access karne ke liye hota hai.

### Example

Maan lo tumhare ghar mein ek computer par web server chal raha hai.

```text
Internal Server IP = 192.168.1.50
Server Port = 3000
```

Router ka public IP:

```text
49.36.100.25
```

Tum router mein port forwarding configure karte ho:

```text
Public IP:Port
49.36.100.25:8080

        |
        v

Internal IP:Port
192.168.1.50:3000
```

Ab external client public IP ke port 8080 par connect karega, aur router traffic internal server ke port 3000 par forward karega.

### Port Forwarding Diagram

```text
External User
      |
      v
49.36.100.25:8080
      |
      v
   ROUTER
Port Forwarding Rule
      |
      v
192.168.1.50:3000
      |
      v
 Internal Web Server
```

## 9. Port Forwarding Kahan Use Hota Hai?

Common uses:

- Self-hosted web servers.
- Remote access services.
- Game servers.
- CCTV/NVR access.
- Development/testing environments.

Important: Port forwarding internal service ko internet se reachable bana sakta hai. Isliye strong authentication, software updates, firewall rules aur secure configuration zaroori hain.

## 10. NAT vs Port Forwarding

| NAT                                    | Port Forwarding                               |
| -------------------------------------- | --------------------------------------------- |
| IP translation technique               | Incoming traffic forwarding rule              |
| Outgoing connections mein commonly use | External-to-internal access ke liye use       |
| Private/public IP mapping              | Public IP port to internal IP/port mapping    |
| Internet access mein help              | Specific internal service ko expose karta hai |

Port forwarding aksar destination NAT (DNAT) ke through implement hota hai.

## 11. SNAT and DNAT

NAT ke do important directions samjho:

### A. SNAT (Source NAT)

SNAT mein packet ka source IP address translate hota hai.

Example:

```text
Before:
Source IP = 192.168.1.10

After:
Source IP = 49.36.100.25
```

Outgoing internet traffic mein commonly use hota hai.

### B. DNAT (Destination NAT)

DNAT mein packet ka destination IP address translate hota hai.

Example:

```text
Before:
Destination = 49.36.100.25:8080

After:
Destination = 192.168.1.50:3000
```

Port forwarding commonly DNAT ka use karti hai.

## 12. NAT Ke Advantages

1. Public IPv4 addresses save karta hai.
2. Multiple private devices ko internet access mil sakta hai.
3. Internal addressing ko public addressing se separate rakhta hai.
4. Internal IP scheme change karne par public addressing ka impact kam ho sakta hai.
5. Port forwarding se selected internal services expose ki ja sakti hain.

## 13. NAT Ke Disadvantages

1. End-to-end connectivity complicated ho sakti hai.
2. Kuch applications ko NAT traversal techniques ki zaroorat pad sakti hai.
3. Incoming connections ke liye extra configuration lag sakti hai.
4. Troubleshooting complicated ho sakti hai.
5. Kuch protocols mein NAT compatibility issues aa sakte hain.
6. NAT device par processing/state tracking ka overhead ho sakta hai.

Important: NAT apne aap mein complete security solution nahi hai. Security ke liye firewall, access control aur secure application configuration bhi zaroori hain.

## 14. CGNAT Kya Hota Hai?

CGNAT ka full form **Carrier-Grade Network Address Translation** hai.

Ismein Internet Service Provider (ISP) multiple customers ko shared public IPv4 infrastructure ke through internet access deta hai.

Example:

```text
Customer A ──┐
Customer B ──┤
Customer C ──┼── ISP CGNAT ── Public Internet
Customer D ──┘
```

CGNAT mein customer ko router par jo WAN IP milta hai, wo actual public IP ke bajay shared/private carrier address ho sakta hai.

CGNAT ke liye commonly used shared address range:

```text
100.64.0.0/10
```

Is range ko Shared Address Space kehte hain. Ye ordinary private IPv4 ranges se different hai.

### CGNAT Ka Problem

Agar tum apne ghar mein server host karna chahte ho, to incoming connection difficult ho sakta hai.

Kyunki tumhare router ke peeche ISP ka CGNAT bhi hota hai.

Possible solutions:

- ISP se public IPv4 address lena, agar available ho.
- ISP se CGNAT removal request karna.
- IPv6 use karna, jab suitable connectivity available ho.
- Secure tunneling solution use karna.

## 15. NAT Traversal Kya Hota Hai?

NAT Traversal techniques applications ko NAT devices ke peeche hone ke bawajood communicate karne mein help karti hain.

Common examples:

- STUN – Public-facing address/port information discover karne mein help.
- TURN – Jab direct connection possible na ho, relay provide karta hai.
- ICE – Available network paths/candidates ko test karke suitable connection establish karne mein help.

Ye technologies real-time communication apps, jaise video calling aur WebRTC, mein important hain.

## 16. NAT aur IPv6

IPv6 ka address space bahut bada hai.

Isliye IPv6 ko NAT ki zaroorat IPv4 jaisi address shortage ki wajah se normally nahi hoti.

IPv6 devices globally routable addresses use kar sakte hain, lekin firewall aur security policies phir bhi important hain.

Important:

- IPv4 networks mein NAT/PAT common hai.
- IPv6 mein end-to-end connectivity possible hai.
- IPv6 mein security ke liye firewall use hota hai; NAT ko security ka replacement nahi samajhna chahiye.

## 17. MERN Developer Ke Liye NAT Kyon Important Hai?

Maan lo tumne MERN application banayi hai:

```text
React Frontend
      |
      v
Node.js + Express Backend
      |
      v
MongoDB Database
```

Development ke time tumhara backend:

```text
http://localhost:5000
```

par run ho raha hai.

Lekin `localhost` sirf current machine ko refer karta hai.

Agar tum chahte ho ki internet se koi user tumhare backend ko access kare, to deployment, public networking, firewall aur routing configuration ki zaroorat hogi.

Agar tum ghar ke network par server host kar rahe ho, to port forwarding ki zaroorat pad sakti hai. Lekin cloud deployment mein usually cloud provider ke networking rules, public IP/load balancer aur firewall configuration use hote hain.

### Security Advice

- MongoDB port 27017 ko public internet par directly expose mat karo.
- Backend secrets aur database credentials frontend mein mat rakho.
- Firewall mein sirf required ports allow karo.
- HTTPS/TLS use karo.
- Production applications ke liye managed hosting/cloud deployment ko prefer kar sakte ho.

## 18. Important Interview Questions

**Q1. NAT kya hai?**

NAT ek technique hai jo network packets ke IP addresses ko translate karti hai.

**Q2. NAT ka use kyon hota hai?**

Mostly IPv4 public address conservation aur private network devices ko internet access dene ke liye.

**Q3. PAT kya hai?**

PAT mein multiple private devices ek public IP share karte hain aur connections ko port numbers se distinguish kiya jata hai.

**Q4. NAT aur PAT mein kya difference hai?**

NAT IP address translation ka general concept hai, jabki PAT IP addresses ke saath port numbers bhi translate karta hai.

**Q5. Static NAT kya hai?**

Ek fixed private IP ko fixed public IP se map karna.

**Q6. Dynamic NAT kya hai?**

Private IP ko available public IP pool se temporarily map karna.

**Q7. Port Forwarding kya hai?**

Router ke public port par aane wale traffic ko specific internal IP aur port par forward karna.

**Q8. SNAT kya hai?**

Packet ke source IP address ko translate karna.

**Q9. DNAT kya hai?**

Packet ke destination IP address ko translate karna.

**Q10. CGNAT kya hai?**

ISP ke network mein multiple customers ke internet traffic ko shared public IPv4 addresses ke through translate karna.

**Q11. Kya NAT firewall ka replacement hai?**

Nahi. NAT aur firewall ke functions alag hain. NAT address translation karta hai, jabki firewall traffic allow ya block karne ki security policy enforce karta hai.

**Q12. Kya IPv6 mein NAT compulsory hai?**

Nahi. IPv6 ka large address space NAT ki address-conservation requirement ko largely remove karta hai.

## 19. Common Mistakes

1. NAT aur PAT ko completely different unrelated techniques samajhna.
2. PAT mein port numbers ka role bhool jana.
3. NAT ko complete firewall/security solution samajhna.
4. Port forwarding ko outgoing traffic forwarding samajhna.
5. SNAT aur DNAT ka difference bhoolna.
6. CGNAT aur normal home NAT ko same samajhna.
7. IPv6 mein NAT compulsory samajhna.
8. Ye samajhna ki port forwarding bina public reachability ke hamesha kaam karegi.

## 20. Quick Revision

- NAT = Network Address Translation.
- Private IP = Local network addressing.
- Public IP = Globally routable internet addressing.
- Static NAT = Fixed one-to-one mapping.
- Dynamic NAT = Public IP pool se temporary mapping.
- PAT = IP + Port translation.
- NAT Overload = PAT ka common name.
- Port Forwarding = Public port se internal service tak traffic forward.
- SNAT = Source address translation.
- DNAT = Destination address translation.
- CGNAT = ISP-level shared IPv4 translation.
- STUN = NAT ke peeche public-facing address information discover karne mein help.
