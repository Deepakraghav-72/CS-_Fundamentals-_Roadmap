# Topic 08 – MAC Address, ARP and RARP

## 1. MAC Address Kya Hota Hai?

MAC ka full form **Media Access Control** hai.

MAC Address ek hardware/network interface address hota hai jo local network par devices ko identify karne ke kaam aata hai.

Example:

```text
00:1A:2B:3C:4D:5E
```

Is address ko generally Physical Address bhi kaha jata hai.

### MAC Address ki Important Properties

- Ethernet MAC address normally 48 bits (6 bytes) ka hota hai.
- Isse hexadecimal format mein represent kiya jata hai.
- Ismein 12 hexadecimal digits hote hain.
- Har hexadecimal digit 4 bits represent karta hai.
- MAC address Network Interface Card (NIC) se associated hota hai.
- Ek device mein Wi-Fi aur Ethernet ke alag-alag MAC addresses ho sakte hain.

### MAC Address Format

```text
00 : 1A : 2B : 3C : 4D : 5E
|     |
|     └── Hexadecimal pairs
└──────── 6 bytes = 48 bits
```

## 2. MAC Address vs IP Address

Dono addresses networking mein important hain, lekin dono ka kaam alag hai.

| MAC Address                              | IP Address                                  |
| ---------------------------------------- | ------------------------------------------- |
| Physical/Link-layer address              | Logical network-layer address               |
| Usually 48-bit Ethernet address          | IPv4 32-bit, IPv6 128-bit                   |
| Local network delivery mein use hota hai | Networks ke beech routing mein use hota hai |
| Network interface se associated          | Network configuration ke according assigned |
| Example: `00:1A:2B:3C:4D:5E`             | Example: `192.168.1.10`                     |

**Easy Example:**

- IP Address = Kisi location ka postal address.
- MAC Address = Local delivery mein particular network interface ki identity.

Note: MAC address ko permanently unchangeable ya universally unique samajhna galat hai. MAC spoofing aur randomized MAC addresses possible hain.

## 3. MAC Address ke Types

### A. Unicast MAC Address

Unicast address ek particular network interface ko identify karta hai.

Example:

```text
00:1A:2B:3C:4D:5E
```

Frame ek specific destination interface ke liye hota hai.

### B. Multicast MAC Address

Multicast address ek particular group of devices ko identify karta hai.

Iska use tab hota hai jab data ek group ke interested devices tak pahunchana ho.

### C. Broadcast MAC Address

Broadcast MAC address:

```text
FF:FF:FF:FF:FF:FF
```

Iska matlab local Layer 2 broadcast domain ke sabhi devices ko frame bhejna.

Example: ARP Request Ethernet par broadcast MAC address use karti hai.

## 4. OUI Kya Hota Hai?

OUI ka full form **Organizationally Unique Identifier** hai.

Traditional globally administered MAC address mein first 24 bits manufacturer/organization identifier ke liye hote hain.

Example:

```text
00:1A:2B : 3C:4D:5E
|-------| |-------|
  OUI      Device-specific part
```

Important:

- OUI manufacturer/organization ko identify karne mein help karta hai.
- Remaining bits organization ke allocation ke according interface identify karte hain.
- Locally administered MAC addresses mein manufacturer OUI se reliable identification nahi hoti.

## 5. ARP Kya Hota Hai?

ARP ka full form **Address Resolution Protocol** hai.

ARP ka kaam IPv4 address se corresponding MAC address find karna hai, jab destination same local network par ho.

### ARP Ki Zaroorat Kyon Padti Hai?

Maan lo:

```text
Your PC:
IP = 192.168.1.10
MAC = AA:AA:AA:AA:AA:AA

Destination PC:
IP = 192.168.1.20
MAC = BB:BB:BB:BB:BB:BB
```

Tumhare PC ko destination PC ka IP pata hai, lekin MAC address nahi pata.

Ab PC ARP ka use karke destination ka MAC address find karega.

## 6. ARP Working Process

ARP ka working process samjho:

### Step 1: ARP Cache Check

Computer sabse pehle apni ARP cache/table check karta hai.

Agar required IP ka MAC address already available hai, to wahi use kar leta hai.

### Step 2: ARP Request

Agar MAC address available nahi hai, to computer ARP Request broadcast karta hai.

Example:

```text
Who has 192.168.1.20?
Tell 192.168.1.10
```

Ye request local network ke devices tak pahunchti hai.

### Step 3: ARP Reply

Jis device ka IP `192.168.1.20` hai, wo ARP Reply bhejta hai.

```text
192.168.1.20 is at BB:BB:BB:BB:BB:BB
```

### Step 4: ARP Cache Update

Sender received MAC address ko ARP cache mein store kar sakta hai.

### Step 5: Data Transmission

Ab sender destination MAC address use karke Ethernet frame bhej sakta hai.

### ARP Working Diagram

```text
PC A                         PC B
IP: 192.168.1.10              IP: 192.168.1.20
MAC: AA:AA...                MAC: BB:BB...

  |                              |
  |---- ARP Request ------------>|
  |    Who has 192.168.1.20?     |
  |                              |
  |<--- ARP Reply ---------------|
  |    192.168.1.20 is at        |
  |    BB:BB:BB:BB:BB:BB         |
  |                              |
  |---- Data Frame ------------>|
  |                              |
```

Note: ARP Request broadcast hoti hai, lekin ARP Reply normally unicast hoti hai.

## 7. ARP Cache Kya Hoti Hai?

ARP Cache ek temporary table hoti hai jisme IP addresses aur unke corresponding MAC addresses store hote hain.

Example:

| IP Address   | MAC Address       |
| ------------ | ----------------- |
| 192.168.1.1  | 11:11:11:11:11:11 |
| 192.168.1.20 | BB:BB:BB:BB:BB:BB |
| 192.168.1.30 | CC:CC:CC:CC:CC:CC |

ARP cache ki help se computer ko baar-baar ARP Request broadcast nahi karni padti.

ARP entries dynamic ya static ho sakti hain. Dynamic entries time ke baad expire ho sakti hain.

## 8. Default Gateway ke liye ARP

Ye interview ke liye bahut important concept hai.

Maan lo:

```text
Your PC:
IP = 192.168.1.10

Default Gateway:
IP = 192.168.1.1

Remote Server:
IP = 8.8.8.8
```

Tumhara PC `8.8.8.8` se communicate karna chahta hai.

Remote server tumhare local subnet mein nahi hai. Isliye PC remote server ka MAC address ARP se find nahi karega.

Instead, PC apne **Default Gateway ka MAC Address** find karega.

Uske baad Ethernet frame router ko bhejega.

```text
PC → Router → Other Networks → Destination Server
```

Important:

- Destination IP remote server ka hi rahega.
- Local Ethernet frame ka destination MAC gateway ka hoga.
- Router next network par forwarding ke liye naya Layer 2 frame banata hai.

## 9. RARP Kya Hota Hai?

RARP ka full form **Reverse Address Resolution Protocol** hai.

RARP ka purpose MAC address ki help se IP address find karna tha.

ARP:

```text
IP Address → MAC Address
```

RARP:

```text
MAC Address → IP Address
```

RARP ka use historically diskless computers mein hota tha, jahan device ko boot hone par apna IP address pata karna hota tha.

RARP ke liye RARP server ki zaroorat hoti thi.

Aaj RARP mostly obsolete hai. Iski jagah DHCP aur BOOTP jaise protocols ne le li hai.

## 10. ARP vs RARP

| ARP                                  | RARP                                |
| ------------------------------------ | ----------------------------------- |
| Address Resolution Protocol          | Reverse Address Resolution Protocol |
| IP se MAC find karta hai             | MAC se IP find karta tha            |
| IPv4 local network mein use hota hai | Historical protocol                 |
| Abhi bhi commonly used hai           | Mostly obsolete                     |
| ARP Request/Reply                    | RARP Request/Reply                  |

## 11. Proxy ARP Kya Hota Hai?

Proxy ARP ek technique hai jisme router kisi doosre device ki taraf se ARP Request ka reply karta hai.

Example:

Agar kisi device ko kisi remote IP ka MAC chahiye aur router Proxy ARP enabled rakhta hai, to router apna MAC address reply mein de sakta hai.

Isse sender frame router ko bhejta hai, aur router aage packet forward karta hai.

Proxy ARP ka use kuch specific network configurations mein hota hai.

## 12. Gratuitous ARP Kya Hota Hai?

Gratuitous ARP ek ARP message hota hai jo device apne hi IP address ke liye send karta hai.

Iske uses:

- Duplicate IP address detect karna.
- Network devices ko updated MAC mapping batana.
- Failover ke baad updated mapping announce karna.

Example:

```text
My IP is 192.168.1.10
My MAC is AA:AA:AA:AA:AA:AA
```

## 13. ARP Spoofing / ARP Poisoning

ARP Spoofing ek network attack hai.

Attacker fake ARP Reply send karke kisi device ko galat IP-to-MAC mapping de deta hai.

Example:

Actual mapping:

```text
Gateway IP = 192.168.1.1
Gateway MAC = AA:AA:AA:AA:AA:AA
```

Attacker fake mapping bhejta hai:

```text
Gateway IP = 192.168.1.1
Attacker MAC = XX:XX:XX:XX:XX:XX
```

Agar victim fake mapping accept kar leta hai, to uska traffic attacker ki taraf redirect ho sakta hai.

Isse Man-in-the-Middle (MITM) attack possible ho sakta hai.

### Prevention

- Dynamic ARP Inspection (DAI), supported switches par.
- DHCP Snooping ke saath network configuration.
- Network segmentation.
- Secure network monitoring.
- End-to-end HTTPS/TLS encryption.

Note: HTTPS traffic ko ARP spoofing se redirect kiya ja sakta hai, lekin proper TLS certificate validation hone par attacker normally encrypted content read ya modify nahi kar sakta.

## 14. IPv6 Mein ARP Use Hota Hai?

Nahi.

IPv6 mein ARP use nahi hota.

IPv6 mein address resolution ke liye **Neighbor Discovery Protocol (NDP)** use hota hai.

NDP ICMPv6 messages ka use karta hai.

Important:

- IPv4 → ARP
- IPv6 → NDP

## 15. Windows Mein MAC Address Kaise Check Karein?

CMD open karo aur command run karo:

```cmd
ipconfig /all
```

Output mein ye field dekho:

```text
Physical Address
```

Ye tumhare network adapter ka MAC address hota hai.

ARP table check karne ke liye:

```cmd
arp -a
```

Specific IP ke liye:

```cmd
arp -a 192.168.1.1
```

ARP cache clear karne ke liye Administrator CMD mein:

```cmd
arp -d *
```

Note: Windows version aur permissions ke according command behavior differ kar sakta hai.

## 17. MERN Developer ke Liye MAC aur ARP Kyon Important Hain?

MERN developer ke roop mein tum mostly HTTP/HTTPS, APIs, Node.js, Express aur MongoDB ke saath kaam karoge.

Lekin jab tumhara application network se communicate karta hai, tab lower networking layers bhi kaam karti hain.

Example:

```text
React Application
       |
       v
HTTP Request
       |
       v
TCP/IP
       |
       v
IP Routing
       |
       v
ARP (Local IPv4 Network)
       |
       v
Ethernet Frame
```

ARP browser ya React application directly handle nahi karta. Ye operating system aur network interface ke networking stack ka kaam hai.

## 18. Common Interview Questions

### Q1. MAC Address kya hota hai?

MAC Address ek link-layer address hai jo local network mein network interface ko identify karta hai.

### Q2. MAC Address kitne bits ka hota hai?

Traditional Ethernet MAC address 48 bits ka hota hai.

### Q3. IP Address aur MAC Address mein kya difference hai?

IP logical addressing aur routing ke liye use hota hai, jabki MAC local link par frame delivery ke liye use hota hai.

### Q4. ARP kya karta hai?

ARP IPv4 address se corresponding MAC address find karta hai.

### Q5. ARP Request broadcast hoti hai ya unicast?

ARP Request normally broadcast hoti hai.

### Q6. ARP Reply broadcast hoti hai ya unicast?

Normally unicast hoti hai.

### Q7. RARP kya karta hai?

RARP historically MAC address ki help se IP address find karta tha.

### Q8. Default Gateway ka MAC Address kyon chahiye?

Remote network par data bhejne ke liye local device ko frame apne default gateway tak pahunchana hota hai.

### Q9. IPv6 mein ARP use hota hai?

Nahi, IPv6 mein NDP use hota hai.

### Q10. ARP Spoofing kya hai?

Fake ARP mapping ke through network traffic ko galat MAC address ki taraf redirect karne ka attack.

### Q11. ARP Cache ka kya purpose hai?

Previously learned IP-to-MAC mappings store karke repeated ARP requests reduce karna.

### Q12. Proxy ARP kya hai?

Jab router kisi doosre IP/device ki taraf se ARP Reply karta hai, use Proxy ARP kehte hain.

## 19. Common Mistakes

1. MAC Address ko IP Address samajhna.
2. ARP ko IP-to-IP mapping protocol samajhna.
3. ARP ko internet ke across routing protocol samajhna.
4. Ye sochna ki remote server ka MAC address directly ARP se milta hai.
5. ARP Request ko unicast kehna.
6. RARP ko modern commonly used protocol samajhna.
7. IPv6 mein ARP use hota hai, aisa samajhna.
8. MAC address ko hamesha permanent aur unchangeable samajhna.

## 20. Quick Revision

- MAC = Media Access Control.
- Traditional Ethernet MAC = 48 bits.
- MAC address = Link-layer address.
- IP address = Logical address.
- ARP = IPv4 address se MAC find karta hai.
- ARP Request = Broadcast.
- ARP Reply = Normally Unicast.
- ARP Cache = IP-to-MAC mappings store karti hai.
- RARP = MAC se IP find karta tha.
- Proxy ARP = Router kisi aur ki taraf se reply karta hai.
- Gratuitous ARP = Apne IP ke liye ARP announcement.
- ARP Spoofing = Fake ARP mapping attack.
- IPv6 = NDP, not ARP.
- Remote network ke liye local device gateway ka MAC use karta hai.
