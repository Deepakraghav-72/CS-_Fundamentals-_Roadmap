# Topic 07: Computer Hardware

## 1. Computer Hardware Kya Hota Hai?

Computer ke wo physical parts jinhe hum dekh sakte hain aur touch kar sakte hain, unhe **Computer Hardware** kehte hain.

Simple words mein:

Computer banane ke liye jin physical components ki zaroorat hoti hai, wo sab hardware kehlate hain.

### Examples

- Monitor
- Keyboard
- Mouse
- CPU
- Motherboard
- RAM
- Hard Disk
- SSD
- Printer
- Speaker
- Webcam

**Example:**

Jab hum computer par typing karte hain, to keyboard hardware hai. Jab hum screen par text dekhte hain, to monitor hardware hai.

## 2. Hardware Ki Main Characteristics

Hardware ki kuch important characteristics:

1. Hardware physical form mein hota hai.
2. Ise hum touch aur see kar sakte hain.
3. Hardware electronic ya mechanical components se bana ho sakta hai.
4. Hardware ko operate karne ke liye instructions aur software ki zaroorat hoti hai.
5. Hardware damage ya faulty ho sakta hai.
6. Hardware ko repair ya replace kiya ja sakta hai.
7. Hardware apne aap user ke instructions ko samajhkar complete task nahi karta; ise software aur firmware ke instructions chahiye.

## 3. Computer Hardware Ke Types

Computer hardware ko uske function aur location ke according different categories mein divide kiya ja sakta hai.

Basic functional categories:

1. Input Hardware
2. Processing Hardware
3. Output Hardware
4. Storage Hardware
5. Communication Hardware

### 3.1 Input Hardware

Input hardware ka use computer ko data aur instructions dene ke liye hota hai.

Examples:

| Device         | Function                      |
| -------------- | ----------------------------- |
| Keyboard       | Text aur numbers enter karna  |
| Mouse          | Pointer move aur click karna  |
| Scanner        | Document scan karna           |
| Microphone     | Voice input dena              |
| Webcam         | Image aur video capture karna |
| Joystick       | Game control karna            |
| Barcode Reader | Barcode read karna            |

### 3.2 Processing Hardware

Processing hardware ka use data aur instructions ko process karne ke liye hota hai.

Examples:

**CPU (Central Processing Unit):**

- Computer ka main processor hota hai.
- Instructions execute karta hai.
- Arithmetic aur logical operations perform karta hai.
- System ke operations coordinate karta hai.

**GPU (Graphics Processing Unit):**

- Graphics aur visual processing ke liye useful hota hai.
- Gaming, video editing aur AI workloads mein use hota hai.
- Parallel processing ke liye designed hota hai.

**Motherboard:**

- Computer ke major components ko connect karta hai.
- CPU, RAM, storage aur other components ko communicate karne mein help karta hai.

### 3.3 Output Hardware

Output hardware processed information ko user tak pahunchata hai.

Examples:

| Device     | Function                       |
| ---------- | ------------------------------ |
| Monitor    | Display show karna             |
| Printer    | Paper par print karna          |
| Speaker    | Sound output dena              |
| Headphones | Audio sunna                    |
| Projector  | Large screen par display karna |
| Plotter    | Technical drawings print karna |

### 3.4 Storage Hardware

Storage hardware ka use data aur programs ko save karne ke liye hota hai.

Examples:

| Device       | Function                     |
| ------------ | ---------------------------- |
| HDD          | Data permanently store karna |
| SSD          | Fast data storage            |
| Pen Drive    | Portable data storage        |
| Memory Card  | Small electronic storage     |
| External HDD | Additional storage           |
| External SSD | Fast portable storage        |

### 3.5 Communication Hardware

Communication hardware ka use computers aur networks ke beech data transfer karne ke liye hota hai.

Examples:

- Network Interface Card (NIC)
- Wi-Fi Adapter
- Ethernet Adapter
- Modem
- Router
- Bluetooth Adapter

**Important:** Router aur modem networking devices hain. Inhe computer hardware ecosystem mein communication hardware ke examples ke roop mein samajh sakte hain, lekin ye computer ke internal components hona zaroori nahi hai.

## 4. Internal Hardware Kya Hota Hai?

Computer ke cabinet ya laptop body ke andar installed physical components ko generally **Internal Hardware** kehte hain.

Ye components computer ke proper functioning mein important role play karte hain.

### Important Internal Hardware Components

#### 1. Motherboard

Motherboard computer ka main circuit board hota hai.

Is par CPU, RAM aur other components connect hote hain.

Functions:

- Components ko connect karna.
- Data communication mein help karna.
- Power distribution ko support karna.
- Different hardware components ke beech coordination enable karna.

#### 2. CPU (Central Processing Unit)

CPU computer ka main processor hota hai.

Functions:

- Instructions execute karna.
- Calculations perform karna.
- Logical comparisons karna.
- Computer operations ko coordinate karna.

#### 3. RAM (Random Access Memory)

RAM ek volatile memory hai.

Ismein currently running programs aur active data temporarily store hote hain.

Important points:

- RAM fast working memory hoti hai.
- Computer band hone par RAM ka data normally erase ho jata hai.
- Zyada RAM multitasking mein help kar sakti hai.

#### 4. ROM (Read Only Memory)

ROM non-volatile memory hoti hai.

Ismein stored data power off hone par bhi generally retain rehta hai.

Modern computers mein firmware flash memory mein store ho sakta hai, jise update bhi kiya ja sakta hai.

#### 5. HDD (Hard Disk Drive)

HDD ek storage device hai jo magnetic technology ka use karke data store karta hai.

Features:

- Large storage capacity available hoti hai.
- Moving mechanical parts hote hain.
- SSD ke comparison mein generally slower hota hai.
- Documents, videos, photos aur software store kar sakta hai.

#### 6. SSD (Solid State Drive)

SSD ek storage device hai jo flash memory use karta hai.

Features:

- HDD se generally faster hota hai.
- Ismein moving mechanical parts nahi hote.
- Fast booting aur application loading mein help karta hai.
- Laptop aur desktop dono mein use hota hai.

#### 7. Power Supply Unit (PSU)

PSU desktop computer ko required electrical power provide karta hai.

Functions:

- AC electricity ko suitable DC power mein convert karna.
- Different components ko required voltage provide karna.

Laptop mein generally external power adapter aur internal power-management circuitry hoti hai.

#### 8. Cooling System

Cooling system computer ke components ka temperature control karne mein help karta hai.

Examples:

- CPU Fan
- Cabinet Fan
- Heat Sink
- Liquid Cooling System

Agar computer zyada heat generate kare, to performance reduce ho sakti hai ya system shutdown bhi ho sakta hai.

#### 9. Network Interface Card (NIC)

NIC computer ko network se connect karne mein help karta hai.

Examples:

- Ethernet NIC
- Wireless Network Adapter

## 5. External Hardware Kya Hota Hai?

Computer ke bahar connect kiye jaane wale physical devices ko generally **External Hardware** ya peripherals kehte hain.

Examples:

- Keyboard
- Mouse
- Monitor
- Printer
- Scanner
- Webcam
- External HDD
- Pen Drive
- Speakers
- Headphones

### Internal vs External Hardware

| Internal Hardware                          | External Hardware                                           |
| ------------------------------------------ | ----------------------------------------------------------- |
| Computer ke andar installed hota hai       | Computer ke bahar connect hota hai                          |
| Main system functioning mein role hota hai | Input, output, storage ya communication mein help karta hai |
| Example: RAM                               | Example: Keyboard                                           |
| Example: Motherboard                       | Example: Monitor                                            |
| Example: CPU                               | Example: Printer                                            |
| Example: SSD                               | Example: External SSD                                       |

**Note:** Kuch hardware internal aur external dono forms mein available ho sakte hain. Example: SSD internal bhi hota hai aur external enclosure ke through bhi use kiya ja sakta hai.

## 6. Hardware Aur Peripheral Devices

Peripheral devices wo additional hardware devices hote hain jo computer se connect hokar uski functionality increase karte hain.

Examples:

Peripheral devices ko broadly three categories mein samajh sakte hain:

## 7. Hardware Kaise Kaam Karta Hai?

Computer hardware different components ke coordination se kaam karta hai.

Example: Jab hum keyboard se `Hello` type karte hain:

1. Keyboard key press detect karta hai.
2. Keyboard computer ko input signal bhejta hai.
3. Operating system aur relevant software input process karte hain.
4. CPU instructions execute karta hai.
5. Graphics system display ko update karta hai.
6. Monitor par `Hello` show hota hai.

## 8. Hardware Aur Software Ka Relationship

Hardware aur software ek doosre par depend karte hain.

**Hardware:** Computer ke physical components.

**Software:** Programs aur instructions jo computer ko batate hain ki kya kaam karna hai.

Example:

- Keyboard = Hardware
- Windows = Software
- Mouse = Hardware
- Google Chrome = Software
- Monitor = Hardware
- MS Word = Software

Hardware ke bina software run nahi kar sakta, aur software ke bina general-purpose computer hardware useful tasks perform nahi kar sakta.

## 9. Hardware vs Software

| Hardware                            | Software                                       |
| ----------------------------------- | ---------------------------------------------- |
| Physical components hote hain       | Programs aur instructions hote hain            |
| Touch kar sakte hain                | Touch nahi kar sakte                           |
| Physical damage ho sakta hai        | Bugs ya corruption ho sakte hain               |
| Repair ya replace kiya ja sakta hai | Install, update ya uninstall kiya ja sakta hai |
| Example: RAM                        | Example: Windows                               |
| Example: Keyboard                   | Example: MS Word                               |
| Example: SSD                        | Example: Google Chrome                         |

### Easy Trick

- Hardware = Physical parts
- Software = Instructions and programs

## 10. Firmware Kya Hota Hai?

Firmware ek special type ka software hota hai jo hardware device ko basic instructions aur control provide karta hai.

Firmware generally non-volatile memory mein stored hota hai.

Examples:

- BIOS/UEFI firmware
- Router firmware
- Keyboard firmware
- Printer firmware

**Example:**

Computer start hone par BIOS/UEFI firmware hardware initialization aur boot process mein help karta hai.

**Important:** Firmware software hi hota hai, hardware nahi.

## 11. Hardware Drivers Kya Hote Hain?

Device driver ek software component hota hai jo operating system ko hardware device ke saath communicate karne mein help karta hai.

Examples:

- Graphics Driver
- Audio Driver
- Printer Driver
- Network Driver

**Example:**

Agar computer mein proper graphics driver nahi hai, to graphics card ki full functionality available nahi ho sakti.

**Remember:**

- Graphics Card = Hardware
- Graphics Driver = Software

## 12. Hardware Failure Kya Hota Hai?

Jab computer ka koi physical component properly work nahi karta, to use hardware failure kehte hain.

Examples:

- RAM faulty hona.
- Hard disk fail hona.
- Laptop fan ka work na karna.
- Monitor display na dena.
- Motherboard damage hona.

### Common Hardware Problems

| Problem                     | Possible Cause                                             |
| --------------------------- | ---------------------------------------------------------- |
| Computer start nahi ho raha | PSU, battery, motherboard ya connection issue              |
| Display nahi aa raha        | Monitor, cable, GPU ya RAM issue                           |
| Computer slow hai           | RAM shortage, storage issue, overheating ya software issue |
| Laptop overheat ho raha hai | Dust, fan issue, poor airflow                              |
| Storage detect nahi ho rahi | SSD/HDD ya connection issue                                |
| No sound                    | Audio device, cable ya driver issue                        |

**Important:** Ek symptom ke multiple causes ho sakte hain. Proper diagnosis ke bina kisi ek component ko faulty assume nahi karna chahiye.

## 13. Hardware Maintenance

Hardware ko properly maintain karne ke liye:

1. Computer ko dust-free rakho.
2. Proper ventilation maintain karo.
3. Laptop ko soft surface par use karne se bacho agar vents block hote hain.
4. Power supply aur cables ko safely handle karo.
5. Liquid ko computer se door rakho.
6. Computer ko safely shut down karo.
7. Important data ka backup rakho.
8. Hardware cleaning ya repair se pehle power disconnect karo.
9. Laptop ya desktop ko open karte waqt electrostatic discharge (ESD) se bachne ki precautions follow karo.

## 14. Important Interview Questions and Answers

**Q1. What is computer hardware?**

Answer: Computer hardware refers to the physical components of a computer that can be seen and touched.

**Q2. Give five examples of computer hardware.**

Answer: CPU, RAM, Motherboard, Keyboard and Monitor.

**Q3. What are the main types of computer hardware?**

Answer: Input hardware, Processing hardware, Output hardware, Storage hardware and Communication hardware.

**Q4. What is internal hardware?**

Answer: Internal hardware refers to the physical components installed inside a computer, such as CPU, RAM and Motherboard.

**Q5. What is external hardware?**

Answer: External hardware refers to devices connected outside the computer, such as Keyboard, Mouse and Printer.

**Q6. What is a motherboard?**

Answer: A motherboard is the main circuit board that connects and enables communication between major computer components.

**Q7. What is CPU?**

Answer: CPU stands for Central Processing Unit. It executes instructions and performs the main processing tasks of a computer.

**Q8. What is RAM?**

Answer: RAM stands for Random Access Memory. It is volatile memory used to temporarily hold active data and programs.

**Q9. What is the difference between HDD and SSD?**

Answer: HDD uses magnetic storage and mechanical moving parts, whereas SSD uses flash memory and has no moving mechanical parts.

**Q10. What is PSU?**

Answer: PSU stands for Power Supply Unit. It converts AC power into suitable DC power for desktop computer components.

**Q11. What is firmware?**

Answer: Firmware is specialized software stored in a device that provides low-level control and instructions for its hardware.

**Q12. What is a device driver?**

Answer: A device driver is software that allows an operating system to communicate with and control a hardware device.

**Q13. What is a peripheral device?**

Answer: A peripheral device is an additional hardware device connected to a computer to provide input, output, storage or communication functions.

**Q14. Can a computer work without hardware?**

Answer: No. Hardware provides the physical components required to run a computer system.

**Q15. Is a graphics card hardware or software?**

Answer: A graphics card is hardware, while its graphics driver is software.
