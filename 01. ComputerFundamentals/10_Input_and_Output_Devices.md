# Topic 10: Input and Output Devices

## 1. Input and Output Devices Kya Hote Hain?

Computer ko operate karne ke liye humein data aur instructions dene padte hain aur computer se result bhi receive karna padta hai.

Is kaam ke liye different hardware devices use hote hain.

### Input Devices

Input devices wo hardware devices hote hain jinki help se hum computer ko data aur instructions provide karte hain.

Examples:

- Keyboard
- Mouse
- Scanner
- Microphone
- Webcam
- Joystick

### Output Devices

Output devices wo hardware devices hote hain jinki help se computer processed information user tak pahunchata hai.

Examples:

- Monitor
- Printer
- Speaker
- Projector
- Headphones
- Plotter

## 2. Input Devices

Chalo ek-ek karke important input devices samajhte hain.

### 2.1 Keyboard

Keyboard ek input device hai jiska use computer mein text, numbers aur commands enter karne ke liye hota hai.

**Keyboard ke main functions:**

- Text typing.
- Numbers enter karna.
- Shortcut commands execute karna.
- Computer ko instructions dena.

### Keyboard Keys Ke Types

| Key Type        | Use                    | Examples                  |
| --------------- | ---------------------- | ------------------------- |
| Alphabet Keys   | Letters type karna     | A–Z                       |
| Numeric Keys    | Numbers type karna     | 0–9                       |
| Function Keys   | Special functions      | F1–F12                    |
| Control Keys    | Commands control karna | Ctrl, Alt, Shift          |
| Navigation Keys | Cursor move karna      | Arrow Keys, Home, End     |
| Special Keys    | Specific actions       | Enter, Esc, Tab, Spacebar |

**Important Keyboard Shortcuts:**

| Shortcut  | Function                  |
| --------- | ------------------------- |
| Ctrl + C  | Copy                      |
| Ctrl + V  | Paste                     |
| Ctrl + X  | Cut                       |
| Ctrl + Z  | Undo                      |
| Ctrl + A  | Select All                |
| Ctrl + S  | Save                      |
| Alt + Tab | Open apps ke beech switch |
| Ctrl + P  | Print                     |

### 2.2 Mouse

Mouse ek pointing input device hai jiska use screen par pointer control karne ke liye hota hai.

**Mouse ke main functions:**

- Click
- Double Click
- Right Click
- Drag and Drop
- Scroll

### Mouse Ke Types

1. Mechanical Mouse – Ball-based mechanism use karta tha.
2. Optical Mouse – Light sensor ka use karta hai.
3. Laser Mouse – Laser-based tracking use karta hai.
4. Wireless Mouse – Wireless connection ke through computer se connect hota hai.

**Note:** Modern mice generally optical ya laser-based tracking use karte hain.

### 2.3 Scanner

Scanner ek input device hai jo physical documents, photos ya images ko digital form mein convert karta hai.

**Example:**

Agar hum kisi paper document ko scanner se scan karte hain, to uski digital copy computer mein create ho sakti hai.

### Scanner Ke Types

- Flatbed Scanner
- Sheet-fed Scanner
- Handheld Scanner
- Drum Scanner

**Flatbed Scanner:** Ismein document glass surface par rakha jata hai aur scanner usko scan karta hai.

### 2.4 Microphone

Microphone ek audio input device hai.

Iska use sound aur voice ko capture karne ke liye hota hai.

Examples:

- Voice Recording
- Video Calling
- Online Meetings
- Voice Commands
- Podcast Recording

### 2.5 Webcam

Webcam ek input device hai jo images aur videos capture karta hai.

Uses:

- Video Calling
- Online Classes
- Video Recording
- Live Streaming
- Face Recognition Systems

### 2.6 Joystick

Joystick ek pointing input device hai jiska use movement aur direction control karne ke liye hota hai.

Uses:

- Video Games
- Flight Simulators
- Training Systems
- Industrial Control

### 2.7 Light Pen

Light Pen ek pointing input device hai jo specially designed display par selection ya drawing ke liye use hota tha.

Ye mostly older computer systems mein use hota tha.

### 2.8 Trackball

Trackball ek pointing device hai jisme user ek ball ko rotate karke pointer control karta hai.

Ye mouse ka alternative ho sakta hai.

Uses:

- Special Workstations
- Industrial Systems
- Limited Desk Space Environments

### 2.9 Touchpad

Touchpad ek pointing input device hai jo mostly laptops mein built-in hota hai.

Uses:

- Cursor move karna.
- Tap aur click karna.
- Scrolling.
- Multi-touch gestures perform karna.

### 2.10 Touchscreen

Touchscreen ek special device hai jo input aur output dono kaam kar sakta hai.

- Output: Screen par content display karta hai.
- Input: Touch ke through user se commands leta hai.

Examples:

- Smartphones
- Tablets
- ATMs
- Touch-enabled laptops

## 3. Special Input Devices

### 3.1 Barcode Reader

Barcode Reader ek input device hai jo barcode ko scan karke usmein encoded information read karta hai.

Uses:

- Shopping Malls
- Supermarkets
- Warehouses
- Inventory Management

### 3.2 QR Code Scanner

QR Code Scanner QR code ko read karke encoded information access karne mein help karta hai.

Examples:

- UPI Payments
- Website Links
- Product Information
- Ticket Verification

### 3.3 OCR

OCR ka full form **Optical Character Recognition** hai.

OCR ek technology hai jo scanned images ya documents mein present printed ya handwritten text ko recognize karke machine-readable text mein convert kar sakti hai.

Example:

Agar hum kisi printed page ko scan karte hain, to OCR technology usmein likhe text ko editable text mein convert kar sakti hai.

**Important:** Scanner image capture karta hai, jabki OCR us image mein text recognize karta hai.

### 3.4 OMR

OMR ka full form **Optical Mark Recognition** hai.

OMR technology specially designed forms par marked bubbles ya boxes ko detect karti hai.

Uses:

- Examination Answer Sheets
- Surveys
- Feedback Forms

Example:

Competitive exam ki OMR sheet mein filled bubbles ko read karna.

### 3.5 MICR

MICR ka full form **Magnetic Ink Character Recognition** hai.

Is technology ka use special magnetic ink se printed characters ko read karne ke liye hota hai.

Uses:

- Banking
- Cheque Processing

### 3.6 Biometric Devices

Biometric devices kisi person ki physical ya behavioral characteristics ko capture ya analyze karte hain.

Examples:

- Fingerprint Scanner
- Iris Scanner
- Face Recognition Camera
- Voice Recognition System

Uses:

- Authentication
- Attendance Systems
- Device Unlocking
- Access Control

**Important:** Biometric recognition system mein sensor ke alawa software algorithms bhi use hote hain.

## 4. Output Devices

Ab important output devices samajhte hain.

### 4.1 Monitor

Monitor ek output device hai jo computer ka visual output screen par display karta hai.

Examples:

- Text
- Images
- Videos
- Graphics
- Applications

### Monitor Ke Types

#### CRT Monitor

CRT ka full form **Cathode Ray Tube** hai.

- Purani monitor technology.
- Size mein bulky hota tha.
- Cathode ray technology use karta tha.

#### LCD Monitor

LCD ka full form **Liquid Crystal Display** hai.

- Liquid crystal technology use karta hai.
- CRT ke comparison mein thin hota hai.
- Generally less power consume karta hai.

#### LED Monitor

LED ka full form **Light Emitting Diode** hai.

Market mein LED monitor generally LCD display ko LED backlighting ke saath refer karta hai.

#### OLED Monitor

OLED ka full form **Organic Light Emitting Diode** hai.

- Har pixel apni light produce kar sakta hai.
- Deep blacks provide kar sakta hai.
- High contrast ke liye known hai.

### 4.2 Printer

Printer ek output device hai jo digital documents aur images ko physical paper par print karta hai.

Printed output ko Hard Copy kehte hain.

### Printer Ke Types

#### A. Impact Printer

Impact printers printing ke liye ribbon aur mechanical striking mechanism ka use karte hain.

Examples:

- Dot Matrix Printer
- Daisy Wheel Printer
- Line Printer

**Dot Matrix Printer:**

- Pins ribbon par strike karti hain.
- Characters dots ke pattern se create hote hain.
- Multi-part forms aur billing systems mein use ho sakta hai.

#### B. Non-Impact Printer

Non-impact printers paper par print karne ke liye mechanical striking mechanism use nahi karte.

Examples:

- Inkjet Printer
- Laser Printer
- Thermal Printer

**Inkjet Printer:**

- Paper par ink ki tiny droplets spray karta hai.
- Color printing aur photo printing mein useful hai.

**Laser Printer:**

- Laser aur toner-based printing technology use karta hai.
- Generally fast document printing ke liye useful hai.

**Thermal Printer:**

- Heat ka use karke special thermal paper par print karta hai.
- Receipts aur billing mein common hai.

### Impact vs Non-Impact Printer

| Impact Printer                               | Non-Impact Printer                                  |
| -------------------------------------------- | --------------------------------------------------- |
| Mechanical striking mechanism use karta hai  | Mechanical striking mechanism use nahi karta        |
| Generally noisy hota hai                     | Generally quieter hota hai                          |
| Example: Dot Matrix                          | Example: Laser Printer                              |
| Multi-part forms ke liye useful ho sakta hai | High-quality text aur image printing ke liye useful |

### 4.3 Speaker

Speaker ek audio output device hai.

Iska use computer se sound output receive karne ke liye hota hai.

Examples:

- Music
- Videos
- Notifications
- Games
- Voice Calls

### 4.4 Headphones

Headphones audio output device hain jo user ko private listening experience provide karte hain.

Examples:

- Wired Headphones
- Wireless Headphones
- Gaming Headsets

### 4.5 Projector

Projector ek output device hai jo computer ki visual information ko large screen ya surface par display karta hai.

Uses:

- Classroom
- Office Presentations
- Cinema
- Training Rooms

### 4.6 Plotter

Plotter ek output device hai jo large-size drawings aur graphics produce karne ke liye use hota hai.

Uses:

- Engineering Drawings
- Architectural Plans
- Maps
- Technical Designs

## 5. Hard Copy Aur Soft Copy

### Hard Copy

Hard copy physical form mein available document ya output hota hai.

Example:

- Printed document
- Printed photograph
- Paper receipt

### Soft Copy

Soft copy digital form mein available document ya output hota hai.

Example:

- PDF File
- Word Document
- Digital Photograph
- E-book

### Difference

| Hard Copy               | Soft Copy                         |
| ----------------------- | --------------------------------- |
| Physical form           | Digital form                      |
| Paper par ho sakti hai  | Computer ya storage mein hoti hai |
| Example: Printed PDF    | Example: PDF File                 |
| Physical space leti hai | Digital storage use karti hai     |

## 6. Input Aur Output Devices Mein Difference

| Input Devices                    | Output Devices                         |
| -------------------------------- | -------------------------------------- |
| Data computer ko dete hain       | Computer ka result show karte hain     |
| User se input receive karte hain | User ko information provide karte hain |
| Example: Keyboard                | Example: Monitor                       |
| Example: Mouse                   | Example: Printer                       |
| Example: Microphone              | Example: Speaker                       |

## 7. Input/Output Dono Kaam Karne Wale Devices

Kuch devices input aur output dono functions perform kar sakte hain.

Examples:

### Touchscreen

- Screen par content display karta hai.
- User ke touch ko input ke roop mein receive karta hai.

### Multifunction Printer

- Print karta hai (Output).
- Scan karta hai (Input).
- Kuch models mein copy aur fax features bhi hote hain.

### Network Interface Card

- Network par data send karta hai.
- Network se data receive karta hai.

### Headset with Microphone

- Headphones audio output dete hain.
- Microphone audio input leta hai.

## 9. Device Drivers Ka Role

Kisi input ya output device ko operating system ke saath properly work karne ke liye device driver ki zaroorat ho sakti hai.

Device driver ek software component hai jo operating system aur hardware device ke beech communication enable karta hai.

Examples:

- Printer Driver
- Graphics Driver
- Audio Driver
- Scanner Driver

**Example:**

Agar printer ka suitable driver available nahi hai, to operating system printer ko properly identify ya use nahi kar payega.

Note: Modern operating systems kai devices ke liye built-in ya automatically installed drivers provide karte hain.

## 10. Important Interview Questions and Answers

**Q1. What is an input device?**

Answer: An input device is a hardware component used to enter data and instructions into a computer.

**Q2. What is an output device?**

Answer: An output device is a hardware component that presents processed information to the user.

**Q3. Give five examples of input devices.**

Answer: Keyboard, Mouse, Scanner, Microphone and Webcam.

**Q4. Give five examples of output devices.**

Answer: Monitor, Printer, Speaker, Projector and Plotter.

**Q5. What is OCR?**

Answer: OCR stands for Optical Character Recognition. It converts text in images or scanned documents into machine-readable text.

**Q6. What is OMR?**

Answer: OMR stands for Optical Mark Recognition. It detects marked bubbles or boxes on specially designed forms.

**Q7. What is MICR?**

Answer: MICR stands for Magnetic Ink Character Recognition. It reads characters printed using special magnetic ink, commonly used in cheque processing.

**Q8. What is a barcode reader?**

Answer: A barcode reader is an input device that scans and reads information encoded in barcodes.

**Q9. What is the difference between impact and non-impact printers?**

Answer: Impact printers use a mechanical striking mechanism, whereas non-impact printers print without mechanically striking the paper.

**Q10. What is a hard copy?**

Answer: A hard copy is a physical printed version of digital information.

**Q11. What is a soft copy?**

Answer: A soft copy is a digital version of information stored or displayed electronically.

**Q12. Is a touchscreen an input or output device?**

Answer: A touchscreen is both an input and output device because it displays information and receives touch input.

**Q13. What is a plotter?**

Answer: A plotter is an output device used to produce large technical drawings and graphics.

**Q14. What is a biometric device?**

Answer: A biometric device captures or analyzes physical or behavioral characteristics for identification or authentication.

**Q15. What is the difference between a scanner and OCR?**

Answer: A scanner captures a physical document as a digital image, whereas OCR recognizes text in that image and converts it into machine-readable text.
