# 23. How a Computer Works (Complete Working of a Computer)

## 1. Introduction

Computer ek electronic machine hai jo user se data receive karta hai, instructions ke according us data ko process karta hai aur meaningful output provide karta hai.

Computer ki working mainly 4 basic operations par depend karti hai:

1. Input
2. Processing
3. Output
4. Storage

In sabhi operations ko hardware aur software milkar perform karte hain.

**Example:**

Maan lo tum calculator mein `10 + 20` enter karte ho.

- Input: Tumne 10 + 20 enter kiya.
- Processing: CPU ne calculation perform ki.
- Output: Screen par 30 show hua.
- Storage: Agar result kisi file mein save kiya, toh storage device par save ho jayega.

## 4. Step 2: Processing – Data Process Karna

Input receive hone ke baad computer instructions ke according data process karta hai.

Is process ka main role **CPU (Central Processing Unit)** perform karta hai.

CPU ko computer ka brain bhi kaha jata hai.

### CPU Ke Main Components

#### A. ALU (Arithmetic Logic Unit)

ALU arithmetic aur logical operations perform karta hai.

**Arithmetic Operations:**

- Addition
- Subtraction
- Multiplication
- Division

**Logical Operations:**

- Greater than
- Less than
- Equal to
- AND
- OR
- NOT

Example:

`10 + 20 = 30`

Ye calculation ALU perform kar sakta hai.

#### B. CU (Control Unit)

Control Unit computer ke different components ki activities coordinate aur control karta hai.

Iske functions:

- Instructions ko fetch karne aur decode karne mein help.
- Required operations ko coordinate karna.
- CPU, memory aur I/O components ke beech control signals manage karna.

#### C. Registers

Registers CPU ke andar present very fast, small storage locations hote hain.

Ye processing ke time temporary data aur instructions hold karte hain.

---

## 5. Step 3: Memory – Data Temporarily Store Karna

Processing ke time CPU ko data aur instructions ki zarurat hoti hai.

Isliye computer RAM aur other memory components ka use karta hai.

### RAM (Random Access Memory)

RAM ek volatile primary memory hai.

Ismein currently running programs aur required data temporarily store hote hain.

**Example:**

Jab tum VS Code open karte ho aur JavaScript code likhte ho, toh running application aur uska working data RAM use karte hain.

### ROM (Read Only Memory)

ROM non-volatile memory hoti hai.

Ismein stored data power off hone ke baad bhi generally safe rehta hai.

Modern computers mein firmware flash memory mein stored hota hai.

### Cache Memory

Cache CPU ke frequently required data aur instructions ko fast access ke liye store karti hai.

### Memory Hierarchy

```text
       Registers
           |
           v
        Cache
           |
           v
          RAM
           |
           v
      SSD / HDD
```

Generally top ki memory faster, smaller aur CPU ke closer hoti hai.

## 8. Computer Mein CPU Instructions Kaise Execute Karta Hai?

CPU instructions execute karne ke liye ek cycle follow karta hai jise **Instruction Cycle** kehte hain.

Iske main steps hain:

### 1. Fetch

CPU memory se required instruction fetch karta hai.

### 2. Decode

Control Unit instruction ko understand karta hai ki kya operation perform karna hai.

### 3. Execute

CPU required operation perform karta hai.

### 4. Store / Write Back

Operation ka result register ya memory mein store kiya ja sakta hai.

```text
       FETCH
          |
          v
       DECODE
          |
          v
       EXECUTE
          |
          v
    STORE / WRITE BACK
          |
          v
     NEXT INSTRUCTION
```

**Example:**

Instruction: `5 + 3`

- Fetch: Addition instruction fetch hui.
- Decode: CPU ne samjha addition perform karna hai.
- Execute: ALU ne 5 + 3 calculate kiya.
- Store: Result 8 register ya required memory location mein store hua.

## 9. Operating System Computer Ko Kaise Manage Karta Hai?

Operating System (OS) user, applications aur hardware ke beech interface provide karta hai.

OS ke bina normal user ke liye computer resources manage karna difficult hota.

### Operating System Ke Main Functions

1. Process Management – Running programs manage karna.
2. Memory Management – RAM allocate aur manage karna.
3. File Management – Files aur folders manage karna.
4. Device Management – Hardware devices manage karna.
5. Security – User permissions aur access control.
6. User Interface – GUI ya CLI provide karna.
7. Resource Management – CPU, memory aur I/O resources coordinate karna.

### Examples

- Windows
- Linux
- macOS
- Android
- iOS

## 10. Computer Start Hone Se Lekar Use Hone Tak Kya Hota Hai?

Jab tum computer ka power button press karte ho, toh booting process start hoti hai.

### Complete Startup Process

1. Power button press karte ho.
2. Motherboard firmware (BIOS/UEFI) start hota hai.
3. POST initial hardware checking perform karta hai.
4. Firmware boot device select karta hai.
5. Bootloader start hota hai.
6. Operating System ka kernel memory mein load hota hai.
7. Required system services start hoti hain.
8. Login screen ya desktop show hota hai.
9. User applications open kar sakta hai.

Ab computer normal use ke liye ready hai.

## 16. Important Interview Questions & Answers

### Q1. How does a computer work?

**Answer:** A computer accepts input, processes data according to instructions, produces output and stores data when required. Hardware and software work together to perform these operations.

### Q2. What are the four basic operations of a computer?

**Answer:** Input, Processing, Output and Storage.

### Q3. What is the role of CPU?

**Answer:** CPU executes instructions, performs calculations and controls or coordinates computer operations.

### Q4. What is the role of ALU?

**Answer:** ALU performs arithmetic and logical operations.

### Q5. What is the role of Control Unit?

**Answer:** Control Unit coordinates and controls the execution of instructions and the activities of computer components.

### Q6. Why does a computer need RAM?

**Answer:** RAM temporarily holds programs and data that are currently being used so that the CPU can access them quickly.

### Q7. What is the difference between RAM and Storage?

**Answer:** RAM is temporary volatile working memory, whereas storage devices such as SSDs and HDDs store data for long-term use.

### Q8. What is an Instruction Cycle?

**Answer:** An instruction cycle is the process through which the CPU fetches, decodes and executes instructions, and stores results when required.

### Q9. What is the role of an Operating System?

**Answer:** An Operating System manages hardware resources, memory, processes, files, devices and provides an interface for users and applications.

### Q10. Why does a computer use binary language?

**Answer:** Digital electronic circuits can reliably represent two states, commonly represented as 0 and 1. Therefore, computers use binary representation to process and store digital information.

### Q11. Can a computer work without software?

**Answer:** A computer requires instructions or firmware to perform useful operations. Without appropriate software, normal user tasks cannot be performed.

### Q12. What happens when we save a file?

**Answer:** The Operating System and file system manage the process of writing the file's data and related information to a storage device such as an SSD or HDD.
